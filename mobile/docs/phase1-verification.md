# Phase 1 — 実機・シミュレータ確認チェックリスト

`EXPO_PUBLIC_ACTION_BOARD_URL` を対象環境に設定したうえで、Expo Go または開発ビルドから WebView を開き、以下を順に確認する。結果は社内共有用にメモする。

## 事前

- [ ] `mobile/.env` に正しいオリジンが入っている（末尾スラッシュなし推奨）
- [ ] 対象 Web がその URL で応答している（ローカルなら PC と同じ LAN、Android エミュなら `10.0.2.2` など）
- [ ] `npx expo start` で該当デバイスから接続できる

## 基本ナビゲーション

- [ ] トップまたはサインイン画面が読み込まれる
- [ ] リンクタップで画面遷移する（同一ドメイン内）
- [ ] Android ハードウェア戻るで WebView が履歴バックする（トップでアプリ終了の挙動は OS 依存）
- [ ] iOS でスワイプバックが期待どおりか（`allowsBackForwardNavigationGestures` 有効時）

## 認証・セッション

- [ ] メール等でのログインが完了する
- [ ] アプリをバックグラウンドにして再度フォアグラウンドしてもログインが維持される
- [ ] WebView をリロードしてもセッションが維持される（Cookie / ストレージの前提確認）

## 主要業務フロー（社内ユーザー想定）

- [ ] ダッシュボードまたはホーム相当に到達できる
- [ ] グッジョブ（ミッション）一覧・詳細を開ける
- [ ] グッジョブの達成・提出フローが最後まで通る（タイプに応じ TEXT / LINK / IMAGE 等）
- [ ] ユーザーグッジョブの作成・編集・公開が必要範囲で通る
- [ ] ランキング・プロフィール等、社内利用で必須の画面を開ける
